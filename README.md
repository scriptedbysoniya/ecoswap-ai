# EcoSwap Neon V2

A Python-first, interactive Streamlit campus exchange prototype with a neon/cyberpunk visual style, animated CSS effects, local SQLite persistence, item listing creation, optional item photo uploads, searchable marketplace, swap requests, request acceptance/decline, and exchange completion.

## Run
1. Extract the ZIP.
2. Open the extracted `EcoSwap_Neon_V2` folder in VS Code.
3. In its terminal run `python -m pip install -r requirements.txt`.
4. Run `python -m streamlit run app.py`.

SQLite database `ecoswap.db` and uploaded images in `uploads/` are created automatically beside `app.py`.

## Prototype limitations
Local-only data; no student verification, cloud database, email notifications, or secure production authentication. This is a demo for local testing.
